# Rijschool Website

Moderne, responsieve website voor een Nederlandse rijschool met lespakketten, voordelen en een online proefles-aanvraagformulier.

## 🚀 Lokale Ontwikkeling

Start de lokale ontwikkelserver via PowerShell:

```powershell
powershell .\server.ps1 -Port 8080
```

Open vervolgens uw browser op: `http://localhost:8080`

## 📁 Projectstructuur

- `index.html` - Hoofdpagina en landingspagina
- `css/style.css` - Styling en responsieve layout
- `js/main.js` - Formulierlogica en interactie
- `server.ps1` - Lokale HTTP ontwikkelserver (geen externe dependencies vereist)
- `.gitignore` - Git configuratie
